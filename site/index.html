How it works

  1. Download and install

    Open the DMG and drag Prune to Applications.

  2. Allow it once

    Open it from Privacy & Security and grant Full Disk Access with the built-in assistant.

  3. Scan and review

    Click Scan, look through what was found, and clean in one click.

Built to never delete the wrong thing

  • Nothing is deleted without your confirmation. You can review each item before cleaning.
  • System folders and personal folders are protected, whatever you select.
  • Personal files and apps go to the Trash. Caches and logs are deleted directly. You can change this in Settings.
  • Usage statistics are anonymous and only sent with your consent. They never include names of files, folders or apps.

Questions

Why does macOS block Prune the first time?

Prune is a free, open-source project made by independent developers, not a company. To open without a warning, a Mac app has to be notarized by Apple, which requires a paid Apple Developer account. Prune isn't notarized yet, so macOS can't confirm who made it and asks you first.

This is a warning that the developer is unknown, not a sign that something is wrong with the app. Because the code is open, you don't have to take our word for it:

  • Read every line of the source code on GitHub.
  • Check that your download is the one we published: each Release lists the checksums in SHA256SUMS, and shasum -a 256 Prune-*.dmg shows yours.
  • Build the app yourself with ./scripts/build_app.sh.

To open it, go to System Settings, Privacy & Security and click Open Anyway. You only do this once. Or run this in Terminal:

xattr -dr com.apple.quarantine /Applications/Prune.app
Why does it need Full Disk Access?

Caches, logs and browser data live in folders macOS protects. Without access, Prune cannot see or clean them.

Will it delete my passwords or bookmarks?

No. Privacy cleaning removes history, cookies and caches only.

Can I undo a cleanup?

Personal files and apps go to the Trash, so you can restore them from there. Caches and logs are removed directly, as apps rebuild them.

How do I update?

Download the new version and replace the app in Applications. What's new is in the changelog.

Is it really free?

Yes. Prune is open source under the GPL-3.0 licence, with the code on GitHub.
